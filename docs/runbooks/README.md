# Operational Runbooks

> **Historical artifact. Not current one-user MCP product documentation.**
> Preserved for platform-era audit/history only. Start current one-user work from `README.md`, `docs/agent-cookbook.md`, `docs/tool-catalog.md`, and `docs/goals/oneuser-tool-coverage.md`.

These runbooks describe incident response and operations for the
platform-era hosted service: a multi-tenant deployment with Postgres,
rate limiting, auth-mode negotiation, and a control plane. The current
product is a local, one-user, stdio-only Clockify MCP with no hosted
service to operate, so these procedures no longer describe normal use.

They are kept in place — like `docs/adr/` — for audit history. Do not
route current operators or agents here for setup or incident guidance.
